# Changelog

Все заметные изменения — здесь. Формат: `## [x.y.z] — дата`, список «добавлено / исправлено / проверено».

## [0.6.0] — 2026-11-09
### Добавлено
- Страница настроек подключения: Base URL, пароль, chat_id, кнопка «Проверить подключение» (`/api/health`).
- Хранение настроек в `~/.config/ouroboros-client/settings.ini` (переживает переустановки).
- Статус-строка в шапке: `Подключено к <адрес> · chat N · M` или честная ошибка + кнопка обновления.
- `Authorization: Bearer` когда задан пароль; chat_id используется и в истории, и в отправке.
### Исправлено
- Soup3 в GNOME 51: `send_and_read_async` требует 4 аргумента — добавлен `GLib.PRIORITY_DEFAULT` в `getJson`/`postJson` (история грузится).
### Проверено
- `flatpak-builder` BUILD_EXIT:0, обе `tsc` чистые в сандбоксе; окно на Xvfb :99, история Main (54 сообщения), скриншот глазами.

## [0.5.0] — 2026-11-09
### Исправлено
- Тот же фикс Soup3 (`GLib.PRIORITY_DEFAULT`), история Main реально грузится (скриншот).
### Проверено
- Скриншот окна глазами; отправка кликом не проверена (нечем нажать в контейнере).

## [0.4.0] — 2026-11-09
### Добавлено
- SVG-иконка в бандле (`scalable/apps`), PNG 512/256/128/64/48/32 на месте.
### Проверено
- Экспорт flatpak подхватил SVG; иконка отрендерена через `rsvg-convert` и посмотрена глазами.

## [0.3.0] — 2026-11-09
### Исправлено
- Ярлык в списке приложений: `Name=Ouroboros`, иконка, metainfo; манифест реально ставит `.desktop`/иконки (`appstream-compose: false` — костыль под контейнер).
### Проверено
- Файлы и экспорт на месте; окно не открывалось (не было дисплея).

## [0.2.0] — 2026-11-09
### Исправлено
- `tsc`: минимальные `globals.d.ts` (без `@types/node`); GJS вынесен в отдельный `tsconfig.gjs.json` (`module: none`, без `export`); запинены версии Gtk 4.0 / Adw 1 / Soup 3.0.
### Проверено
- Настоящая сборка: `tsc` 5.9.3 чистый, `flatpak-builder` BUILD_EXIT:0, GJS грузится без JS ERROR (дисплея не было).

## [0.1.0] — 2026-11-09
### Добавлено
- TS-клиент gateway: `types` (по живому `/api/contract` abi 7.0), `config`, `api` (fetch), `ws` (авто-реконнект + очередь), `cli` (`check`/`chat`/`task`), GJS-окно GTK4/Libadwaita, flatpak-манифест GNOME 51 + node26/typescript.
